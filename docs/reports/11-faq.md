## Поведение

| Требование | Реализация |
|---|---|
| Заголовок | `<h3><button aria-expanded aria-controls></button></h3>` |
| Панель | `id`, `role="region"`, `aria-labelledby` кнопки; закрытая — `inert` |
| Клавиатура | Tab по кнопкам, Enter и Space переключают (проверено), фокус — 2 px лайм внутри пункта |
| Несколько открытых | да, состояние — набор открытых id; первый открыт по умолчанию |
| Анимация | `grid-template-rows` 0fr → 1fr, 250 ms ease-out (замер: 136 px через 120 ms → 152 px), иконка плюс → минус |
| reduced motion | без анимации (сразу 152 px) |
| JSON-LD FAQPage | не добавлен (ответы — черновики) |
