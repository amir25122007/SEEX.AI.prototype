## 2. Смена заголовка Hero

| Пункт | Реализация |
|---|---|
| Данные | `src/data/heroTitles.ts`: 5 пар «слово / чип», вторая строка, текст для h1, интервал 12 000 мс |
| Компонент | `src/components/landing/HeroTitle.tsx` (client): `HeroScenarioProvider` (общее состояние заголовка и чипов), `HeroTitle`, `useHeroScenario` |
| Стиль | прежние классы `titleLine` / `titleLime` / `titleWhite`: шрифт, 75 px, обводка, тень и позиция не изменились |
| Ширина слова | предел = min(1280, 1.1 × ширина «ЗА ПАРУ МИНУТ»), замер скрытой линейкой после загрузки шрифтов; уменьшается только `font-size` этой строки |
| Высота | строка фиксирована 90 px, слова лежат абсолютно → h1 185 px во всех кадрах; композер y 653.09, чипы y 887.08 не двигаются |
| Переход | 600 мс: старое слово 0–420 мс вверх −36 px + fade + blur 6; новое 180–600 мс снизу +36 px; только transform / opacity / filter |
| Чип | чип текущего сценария: hover-яркость (`brightness-105`) + мягкое лаймовое свечение, переход 600 мс |
| Пауза | наведение на заголовок (зона = ширина текста, не всей полосы); `visibilitychange`; остаток интервала сохраняется |
| Reduced motion | смены нет, «ПРЕЗЕНТАЦИЯ», подсвечен чип «Презентация» |
| Доступность | h1 = sr-only «Презентация за пару минут»; анимируемая часть `aria-hidden`; aria-live нет |
| SSR | первый кадр «ПРЕЗЕНТАЦИЯ» (проверено в HTML ответа) |
