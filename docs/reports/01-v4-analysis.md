## 2. Проблемы экспорта

| Проблема | Следствие |
|---|---|
| В SVG нет `<text>`/`<tspan>`, текст переведён в контуры (хотя Outline text был выключен) | Тексты дословно можно взять только с PNG |
| Id слоёв есть, но имена текстовых слоёв устарели (все шаги How it works — «[01] ВЫБЕРИТЕ ЗАДАЧУ», кнопки — «Получить консультацию») | Имена слоёв не годятся как источник текста |
| Id закодированы как UTF-8, прочитанный в Latin-1 / cp1252 (`&#208;&#159;…`) | Для чтения id нужна перекодировка |
| Имена zip-архивов не совпадают с содержимым | Ориентироваться по именам файлов внутри |
