## Карусель

| Параметр | Реализация |
|---|---|
| Логических слайдов | 5 (5 точек, как в Figma) |
| Содержимое | 1 «Сценарии» (макет), 2 «Кадры», 3 «Карточка товара», 4 = 2, 5 = 3 (TODO в `src/data/howItWorks.ts`) |
| Отличие от решения «4–5 = 1–2» | в эталоне слева от слайда 1 стоит «Карточка товара», справа — «Кадры». При 4–5 = 1–2 слева от слайда 1 оказался бы слайд 5 = «Кадры», и стартовый кадр не совпал бы с эталоном. Поэтому 4–5 повторяют 2–3 |
| Лента | слайды разного размера (макет 567.8 широкий, растры около 430), gap 24 между внешними краями; центр активного слайда держится на x 729.45 (центр макета в эталоне) |
| По кругу | по 3 клона с каждой стороны: шаг на клон анимируется, затем без анимации перескакивает на настоящий слайд; ввод на эти ≤ 400 мс игнорируется |
| Переход | `transform` 400 ms ease-out (замер: transitionend через 415 мс после клика) |
| reduced motion | без анимации, сразу на настоящий слайд |
| A11y | `role="region"`, `aria-roledescription="карусель"`; слайды `role="group"` «N из 5», неактивные и клоны `aria-hidden`; alt только у активного; точки — кнопки «Слайд N» с `aria-current`; sr-only live-статус «Слайд N из 5» |
