## 2. Плавание

| Параметр | Значение |
|---|---|
| Ось X | ±1.75 / ±2.8 / ±4.2 px (far / mid / near, 70 % амплитуды), период 9–14 с |
| Ось Y | ±2.5 / ±4 / ±6 px, период 7–11 с |
| Некратность | если X/Y ближе 0.08 к целому числу, X сдвигается на 0.7 с |
| Фаза и направление | отрицательный delay в пределах периода, `alternate` / `alternate-reverse` от хэша id |
| Анимаций | 26 (13 карточек × 2 оси); на элементах с `filter` — 0 |
| Персонаж, заголовок, композер, chips, header | не анимируются |
| Измеренный размах за 12.5 с (x, y), px | far до 3.4 × 5.0; mid до 5.5 × 8.0; near до 7.3 × 12.0 |
| Плавность, Chromium (5 с rAF, 1440 и 1920) | 301 кадр, p50 16.7 мс, p95 16.7 мс, max 16.8 мс, кадров > 20 мс — 0 |
| `scrollWidth` во время анимации | 1440 / 1920 |
| reduced motion | анимаций и `will-change` нет |

## Safari

| Риск | Мера |
|---|---|
| `var()` в keyframes в Safari может уводить анимацию с компоновщика | keyframes статичные, без `var()` |
| Перерисовка blur каждый кадр | анимируются только обёртки, у них нет `filter` |
| Субпиксельная дрожь | `translate3d` + `will-change: transform` на обёртках |
| `overflow: clip` (Safari 16+) | перед ним стоит `overflow: hidden` как запасной вариант |
| Проверка | WebKit в кэше Playwright нет, проверено только в Chromium; в Safari нужна ручная проверка |
