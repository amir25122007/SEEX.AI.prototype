# SeexAI landing — project context

Актуально на 2026-10-10. Этот файл заменяет правила из `design-refs/EXPORT_CHECKLIST.md` (v3, устарел) и раздел «Source of truth» в `README.md`.

## Правила

- **Источник истины — финальная версия макета в `design-refs/final/`** (с 2026-10-10): `page-ref@1x.png` (вся страница 1440×8536), `raw/Main page v4.svg` (SVG всей страницы: текст в контурах, растры base64, **имена слоёв актуальны** и равны видимому тексту), `raw/Main page v4.pdf`, `texts-from-pdf.txt` (настоящие тексты; пробелы местами склеены — восстанавливать по PNG; приоритетнее распознанных раньше). Эталоны секций нарезаны в `design-refs/final/<section>-ref@1x.png`. **`design-refs/v4/` устарел** и хранится для истории.
- **Шрифты текста:** в финальном макете весь текст, кроме заголовков (Druk) и акцентов Unbounded, набран SF Pro Text (трекинг 0, номера `[01]` — SF Light с разрядкой) → на сайте стек `-apple-system, BlinkMacSystemFont, "SF Pro Text", Inter, system-ui, sans-serif` (`--font-sans`, шрифт `body` по умолчанию): на Apple — системный SF Pro, на остальных — Inter. Файлы SF Pro не загружаем (лицензия Apple). IBM Plex Mono больше не используется и не загружается. Inter шире SF Pro Text ≈ на 5 % — не компенсируем; там, где из-за этого текст наезжал бы на элементы или ломал строки макета, решение описано в отчёте 09.
- **Scope — вся страница Main page v4** (page-ref 1440×8724, расширено 2026-10-10), в порядке страницы:
  1. Header + Hero
  2. Сценарии («Готовые сценарии под вашу задачу»)
  3. Features («От идеи до готового результата»)
  4. How it works («Путь к результату всего за 3 шага»)
  5. Learning (обучение + бегущие строки)
  6. Дальше: для кого, тарифы, FAQ, финальный CTA + footer — экспорт в `design-refs/v4/raw/6`, разбираем отдельным этапом.
- **Только desktop 1440.** Mobile/tablet не делаем; на чуть более узких окнах страница просто не должна ломаться.
- **Figma MCP не используем** (лимит Starter-плана). Работаем только по ручному экспорту в `design-refs/v4/`.
- **Шрифты Druk Text Wide Cyr и Neuropol подключены (2026-10-13, отчёт 15):** `public/fonts/DrukTextWideCyr-Medium.woff2`, `public/fonts/Neuropol-Regular.woff2` (swap + preload через `src/lib/brandFonts.ts`). Исходники `.otf` — только в `design-refs/fonts/` (вне git), в `public/` не класть. Позиции Druk-текста сверены с эталонами: в Chrome Druk стоит на 0.5–2 px выше, чем в Figma, поправка — `translate` / `--druk-dy` в CSS секций (не `top`, чтобы не сдвигать описания). SF Pro заменён на Inter.
- **Не коммитить и не пушить без явного запроса.** После каждого этапа — стоп и отчёт.
- Значения не выдумываем: тексты, размеры, цвета берём из эталонов v4.
- **Стыки секций бесшовные** (для всех текущих и будущих секций). Фон страницы перетекает непрерывно, как в `page-ref@1x.png`. У секций нет собственного непрозрачного фона с жёсткой границей. Общая подложка лежит на `<main>` (`--gradient-page`: #4A100E на y 1500 → `--color-page` #230F01 к y 2400). Свечения секций полупрозрачные и уходят в ноль до края. Проверка: вертикальный профиль цвета скриншота всей страницы (x = 20 / 360 / 720 / 1080 / 1420 и края на 1920), скачков на 1–3 px вне контента быть не должно.

## Принятые решения (2026-10-10)

1. **Hero:** фоновые floating cards постоянно «плавают» (с 2026-10-10, отчёт 14): амплитуда far ±6 / mid ±10 / near ±15 px (X — 70 %), периоды X 6–8 с, Y 4.5–6.5 с; mid и near ещё наклоняются ±0.6° (9–12 с).
2. **Scenarios:** два ряда карточек — бегущие ленты в противоположных направлениях, ~40 px/с, пауза на hover; карточка под курсором получает hover-состояние из Figma (лайм-обводка и свечение).
3. **Learning:** бегущие строки ~40 px/с, ленты в противоположные стороны, пауза на hover. Пауза лент (Scenarios и Learning, общий `ui/Marquee`) с 2026-10-13 — через Web Animations API (`MarqueePause.tsx`: pointerenter/leave, focusin/out → `pause()` / `play()`), а не `animation-play-state`: в WebKit CSS-пауза не держала время, и после ухода курсора лента прыгала вперёд на пройденное за паузу расстояние.
4. **How it works:** 5 точек пагинации как в Figma; слайды 4–5 повторяют слайды 2–3 (подтверждено 2026-10-10: так стартовый кадр совпадает с эталоном), в коде TODO под реальный контент. Макет «Сценарии» — PNG @2x, отрендеренный из SVG-группы Frame 373 (SVG 9.1 МБ из public/ удалён).
5. **Растры** «Изображения» (Features) и персонаж Learning — оставляем текущее разрешение.
6. **Анимации:** только transform/opacity (включая отдельные свойства `translate`), чистый CSS, без библиотек; при `prefers-reduced-motion` — статично.
7. **Бюджет:** весь оставшийся лендинг ~5 часов. Работать быстро, без лишних итераций, но без потери точности по эталону.

8. **Scenarios (2026-10-10):** `inert` стоит на ссылках дубликатов лент, а не на всей копии (иначе не работает hover) — принято. `IconButton` и `ArrowUpThinIcon` оставляем.

9. **Навигация (2026-10-10):** пункт «Модели» в header и footer ведёт на `#features` (отдельной секции нет). Якоря прокручиваются плавно (`scroll-behavior: smooth`, кроме reduced motion), заголовок секции встаёт в 60 px от верха (`scroll-margin-top` в globals.css).

10. **Заголовок Hero (2026-10-10, отчёт 14):** первая строка меняется каждые 3 с (с 2026-10-13; переход 450 мс) по `src/data/heroTitles.ts` (Презентация → Карточка товара → Резюме → Отчёт в Excel → Обработка фото), вторая всегда «ЗА ПАРУ МИНУТ». Слово шире min(1280, 0.95 × ширина второй строки) уменьшается: в Neuropol так лаймовое слово не доходит до near-карточки справа даже в пике плавания (отчёт 15). Сейчас уменьшаются «КАРТОЧКА ТОВАРА» (65.33 px) и «ОБРАБОТКА ФОТО» (70.98 px). Чип текущего сценария подсвечен. Пауза только в скрытой вкладке (паузу при наведении убрали 2026-10-13: курсор почти всегда над большим заголовком, ротация замирала); при reduced motion — всегда «ПРЕЗЕНТАЦИЯ». h1 для скринридеров и поиска — постоянный «Презентация за пару минут».

11. **Pricing, hover / focus-within (2026-10-13):** карточка `scale: 1.04` (без scale при reduced motion), `brightness(1.08) saturate(1.05)`, своё свечение ярче (opacity `::before`), z-index выше; остальные — `brightness(0.85) saturate(0.9)` через `:has()`; переходы 250 мс ease-out. «Сердцебиение» отменено.

Особенности SVG:
- Текст в SVG — **контуры** (`<path>`), `<text>` нет, хотя Outline text был выключен. Id слоёв есть, но имена текстовых слоёв **устарели** и часто не совпадают с видимым текстом (например, во всех трёх шагах How it works слой называется «[01] ВЫБЕРИТЕ ЗАДАЧУ»). Тексты берём **с PNG**.
- Id слоёв закодированы как UTF-8, прочитанный в Latin-1 (`&#208;&#159;…`); чтобы получить кириллицу, их нужно перекодировать.
- Растры встроены в SVG как base64 PNG. Glow-эллипсы и blur-фильтры есть как векторы (`feGaussianBlur stdDeviation` = Figma blur / 2).
