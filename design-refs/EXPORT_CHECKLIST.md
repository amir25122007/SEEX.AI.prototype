## Как экспортировать и сохранять

**Поиск узла.** В Figma: Cmd+F не ищет по id. Выдели frame через Layers по имени слоя из списка; id можно сверить в адресной строке (`node-id=1394-3521` = `1394:3521`).

**Экспорт.** Правая панель → Export → `+` → формат и масштаб из строки чек-листа → Export.
- PNG @1x — для замеров геометрии (1 px = 1 CSS px).
- PNG @2x — для деталей и для растров в `public/`.
- SVG — в настройках экспорта включи **Outline text: off**, **Include "id" attribute: off**, **Simplify stroke: on**.

**Glow / свечения.** Экспортируй сам ellipse или группу, не родительский frame. SVG нужен ради цветов, opacity и blur (`feGaussianBlur stdDeviation`) — растр их не даёт.

**Пометки в строках.**
- «уже есть: …» — экспортировать не нужно, файл в проекте.
- «сверить» — экспортируй во временную папку и сравни с указанным файлом (одинаковая картинка = не нужен).

**Тексты.** Для каждой секции создай файл `design-refs/<section>-texts.md` и копируй тексты так:

```md
## 1394:3514 · Frame 268 description
Выберите задачу, добавьте свой контент и получите готовый результат. SeexAI поможет подобрать модель, промпт и настройки.
```

- Один заголовок `## <node id> · <имя слоя>` на каждый текстовый слой.
- Текст — дословно, с исходным регистром (как в поле редактирования, а не как отображается с UPPER-стилем).
- Ручные переносы строк (Shift+Enter в Figma) сохраняй переносами строк.
- Если слой содержит несколько стилей (например, часть оранжевым), отметь это строкой `> оранжевым: «…»`.
- Для слоёв внутри instance (id вида `I1394:3516;225:1149`) двойным кликом проваливайся внутрь instance и копируй оттуда.

Имена `<section>`: `how-it-works`, `learning`, `audience`, `pricing`, `faq`, `final-cta`.
